### PCIe 槽（MSI 手冊 p.21 / spec 頁，官方）
- **PCI_E1**（CPU）：Gen5 x16（現時 5090 行足 x16）
- **PCI_E2**（CPU）：Gen5 x4 — 同 PCI_E1、M2_2 **共用** 16 lanes；插佢 → 5090 跌 x8
- **PCI_E3**（晶片組）：Gen4 x4，**唔共用** → 5090 保持 x16 ✅ ← 3060 插呢條

## 1. 目標（驗收標準）

1. 3060 插 PCI_E3，Windows 認到兩張 NVIDIA 卡：`nvidia-smi -L` 出 2 行。
2. 5090 插卡後仍然 **Gen5 x16**（`nvidia-smi --query-gpu=pcie.link.gen.current,pcie.link.width.current`）。
3. 3060 屬 agent 專用：冇任何 SK 遊戲／日常程式用佢（VRAM / 功耗可獨立量）。
4. 一部可長期運行嘅 VM（我嘅私人電腦）：SSH 入到、可裝軟件、有自己檔案系統、**唔搶 SK 焦點**。
5. 打機影響量度：加卡前後 CS2/MC FPS 差 ≤ 噪音水平；5090 遊戲中 3060 跑模型唔影響 FPS。
6. 全程可還原：拆卡／移除 VM = 返今日狀態，零資料損失。

## 2. 分階段

### Phase A — 硬件（SK 親手，我做 checklist + 事後驗證）
1. 關機、拔電源線、按開關放電。
2. 3060 插 **PCI_E3**（最底條 x16），插 8-pin PCIe 電源。
3. 開機 → 我跑驗收 1/2。
- 失敗處理：唔 POST / 認唔到 → 拆卡開機 = 完全還原（冇改任何軟件）。

### Phase B — VM（CPU-only，最穩）
- Hyper-V Gen2 VM，Ubuntu（ISO 已有：`Downloads/drive & app installer/ubuntu-24.04.4-desktop-amd64.iso`）
- 起手 4 vCPU / 8GB RAM / 120GB 動態 VHDX（可加）；停機時唔佔 CPU
- 控制通道：SSH（主）＋ 需要 GUI 時 x11vnc／Xvfb **無頭**（零窗口、零搶焦點）
- 網絡：獨立 Internal switch，唔接 SK 嘅分享資料夾（隔離）

### Phase C — 3060 專用（兩個做法，二選一）
- **C1（建議先做）**：3060 留 host，只行 agent 模型服務（Ollama/llama.cpp，`CUDA_VISIBLE_DEVICES` 指去 3060），VM 經內部虛擬網絡打 API。
  - 零 hack、零 driver 風險；打機期間一樣用得到。
- **C2（真 passthrough 入 VM）**：Hyper-V GPU-PV
  - `Get-VMPartitionableGpu` → `Set-VMPartitionableGpu -PartitionCount N`
  - `Add-VMGpuPartitionAdapter -VMName <vm> -InstancePath "<3060 instance path>"`（NVIDIA 官方文件：多 GPU 要指定 instance path）
  - 再 copy host driver 檔入 guest（社群方法，參考 Easy-GPU-PV `CopyFilesToVM.ps1`）
  - ⚠️ Microsoft 官方立場：DDA/GPU-P「not supported on desktop-class hardware or client OS such as Windows 10/11 Pro」
  - ⚠️ Guest 必須 Windows；Win10 host → guest 要 Win10 對版本；需要 ISO（要下載）+ license（未啟用都可運作，只有水印）
  - ⚠️ 每次 host driver 更新後要重跑 driver copy（`Update-VMGpuPartitionDriver.ps1`）
  - 還原：`Remove-VMGpuPartitionAdapter` + `Set-VMPartitionableGpu -PartitionCount 1`

### Phase D — 拒絕清單
- ❌ App Sandbox（Easy-GPU-PV 後繼）：官方要求 **Windows 11** host，SK 係 Win10 → 唔適用
- ❌ DDA：client OS 官方唔支援，而且會令 host 完全失去張卡

## 3. 風險 / 最壞情況 / 還原

| 風險 | 最壞 | 還原 |
|---|---|---|
| 插卡整壞／唔 POST | 機開唔到 | 拆卡 → 開機（軟件零改動） |
| 3060 係壞卡／礦卡 | 白做 | 拆卡，賣/退 |
| GPU-PV 令 guest BSOD | 只有 VM 死 | `Remove-VMGpuPartitionAdapter`；host 不受影響 |
| GPU-PV 撞 WSL2 GPU | 其中一邊 GPU 失效 | 3060 同 5090 分開用；先實測 WSL2 仍正常 |
| Driver 更新後 VM 冇 GPU | VM 要重 copy driver | 跑 Update script |
| 磁碟 | 273GB free，VM 食 120GB → 剩 ~150GB | 可加 M.2_3/4 第二條 SSD（另購） |
| 機箱熱/風道 | 3060 底部吸唔到風 | 量 GPU 溫度；必要時調風扇曲線 |

## 4. 未解／要 SK 決定

1. **幾時插卡**（要關機 10–15 分鐘）。
2. **Guest OS**：Ubuntu（現成 ISO、免費、零干擾、CPU-only）定 Windows（要下載 ISO + license 問題，但先做到 GPU-PV）。
3. Phase C 行 C1（host 服務）定直接 C2（GPU-PV 入 VM）。
4. 3060 嘅 VRAM 版本（插卡後 `nvidia-smi` 即知，唔使 SK 記）。

## 5. 論壇／GitHub issue 真實案例（已吸收，來源見 skill）

規則已寫入 skill **`windows-hyperv-gpu-pv-vm`**（category windows）。重點：

| 案例 | 出處 | 對我哋嘅影響 |
|---|---|---|
| **Win10 冇得揀邊張 GPU**：`-InstancePath` 係 Win11 API；Win10 會「自動揀」，多卡時甚至每次重開機都可能唔同 | Level1Techs #172234（多頁）、mu0.cc 指南 | ⚠️ 必須先實測本機 cmdlet 行為；如果 Win10 唔 honor，就要「暫時停用其他 GPU」先分區，或者改用 C1 |
| 多張同名 GPU → `InstancePath` 型別錯誤 | Easy-GPU-PV issue #34 | 5090／3060 唔同名 → 冇事，但腳本 AUTO 仍可能揀錯 |
| **WSL2 同 GPU-PV 撞 → guest 內 Code 43** | Easy-GPU-PV deepwiki「WSL Interference」 | SK 有 Ubuntu + docker-desktop WSL distro → 開工前 `wsl --shutdown`，出事就 `wsl --unregister` 試 |
| host 更新 GPU driver 後 guest 即 Code 43，要重 copy driver 檔 | Level1Techs（大寫警告）、issue #407 | 例行維護步驟：每次升 NVIDIA driver 之後重做 driver copy |
| VM 開唔到「MMIO region above supported physical address range」 | issue #40、#116 | 降 `-HighMemoryMappedIoSpace 512MB` |
| GPU-P 唔支援 checkpoint；VM 要用靜態記憶體、Gen2 | Level1Techs、Parsec 作者 | VM 設定照跟；backup 改用「關機後 copy VHDX」 |
| 分區 GPU **冇顯示輸出** → 要虛擬顯示器 driver／dongle；RDP＋Hyper-V Video 只 30fps 亦會黑屏 | Level1Techs、Easy-GPU-PV README | 無頭方案：guest 內 OpenSSH + VNC（headless client 驅動），唔開窗 |
| Linux guest + GPU-PV 基本唔通 | Level1Techs #198336 | 確認：GPU 入 VM 一定要 Windows guest |
| DLSS／Vulkan／OpenGL 喺 GPU-PV guest 要 forwarding DLL 先 work（有人喺 RTX 3060 上做成功） | Level1Techs 後段 | 進階；如果 guest 要跑帶 OpenGL 嘅嘢（例：Minecraft）先處理 |
| Easy-GPU-PV 已 **archived**（2026-06）；後繼 App Sandbox 要 **Win11** | GitHub API 實查 | 我哋用 Windows 內建 cmdlet，唔靠第三方 app |
